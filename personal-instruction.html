01 PORTRAIT

不按单一路线生长

信息来自公开作品与学习记录，剥离所有身份字段后只留下真正有用的部分。

MINDSET / ENTP

对新问题保持兴奋，习惯快速建立假设，再用实验推翻不够好的答案。

CORE / REVERSE

从汇编、ABI 和内存布局出发，追踪控制流、数据流、反调试、加密逻辑与运行时行为。

RANGE / CROSS-DOMAIN

从 Web 全栈、密码学和 PWN 获得侧视角，把 Android、固件、内核与 AI 系统安全连接起来。

OUTPUT / EXPLAIN

偏爱能被复现的教程、脚本和工具。写作不是终点，而是检验理解是否完整。

02 CAPABILITY MAP

现在在做的事

不使用夸张的熟练度百分比，直接列出能够动手分析、编写脚本、复现和出题的技术面。

Reverse / foundations

x86 / x64 / ARM64 汇编，寄存器与标志位、栈帧、调用约定、ABI、结构体恢复、堆栈与进程内存布局。

Reverse / executable formats

PE / ELF / Mach-O 的节区、导入导出、重定位、链接与加载过程；IDA Pro、Ghidra、x64dbg 的静态与动态联动。

Reverse / protection

UPX 与 PyInstaller 提取、常见反调试与花指令、控制流混淆、OLLVM 相关还原思路，以及关键算法的定位与验证。

Android analysis

APK 与 Smali、jadx / JEB、JNI 定位、Frida Java / Native Hook、DEX 运行时获取、so 层参数追踪与二次分析。

Crypto reconstruction

TEA / XTEA、AES-CBC、SM4-ECB、RC4 和 RSA 常见攻击面的特征识别、脚本还原与结果交叉验证。

PWN / control flow

ret2win、ret2text、ret2shellcode、ret2libc、ret2csu 与 ROP 链构造；栈迁移、格式化字符串、syscall 与基础沙箱绕过思路。

PWN / heap & mitigations

堆布局、tcache、UAF、OOB 等基础机制；NX、Canary、PIE、RELRO、ASLR、seccomp 的识别、影响判断与利用约束分析。

Kernel & system

Linux 内核漏洞机制与调试路径，用户态 / 内核态边界、kASLR、cred、usercopy、常见内核 UAF / OOB 题型的学习与复现。

Web full stack

HTML / CSS / JavaScript 前端体验、Python / PHP / Node.js 服务端、API 与认证设计、数据库交互、Docker 化部署和页面性能调优。

Web security

SQL 注入、XSS、文件上传、命令执行、反序列化、认证与授权缺陷的代码审计、Burp 验证、修复思路与复盘写作。

CTF authoring

Reverse / PWN / Web 题目设计，漏洞点与预期解法控制、checker、Docker 交付、题解沉淀、环境验收和自动化验证。

Firmware, AI & tooling

固件拆包、QEMU / Unicorn 仿真、协议观察与 AI 系统攻击面调研；Python、C / C++、Git、WSL、Docker 和自动化工具链。

03 PRINCIPLES

学习不是收藏知识点

  1. 先让样本说话，再让经验下结论。
  2. 静态结果、动态行为与脚本输出互相校验。
  3. 解决一次问题，也顺手沉淀下一次的工具。
  4. 保持广度，但把长期深度留给二进制世界。
